1 Analogy (Samajhne ke liye)

Blue-Green: Stage par 2 bilkul same setups hain (Blue aur Green). Pehle Blue par performance ho rahi hai. Phir achanak se light (traffic) Green par switch kar di jati hai. (Instant Switch).

Canary: Ek naya show shuru hua hai, pehle sirf thori si audience (10%) ko andar bhej kar dekhte hain ke unhe pasand aaya ya nahi. Agar theek hai, toh baqi 90% ko bhi bhej dete hain.

2 Core Concepts

  • Rollout CRD: Standard Deployment ki jagah hum Argo ka Rollout object use karte hain. Yeh boht smart hota hai.
  • Canary Analysis: Argo Rollouts check kar sakta hai ke naye version (v2) par kitne errors aa rahe hain. Agar errors ziada hon, toh bina kisi insaan ke khud ba khud rollback (v1 par wapas) kar deta hai!
  • Integration: Yeh Gateway API ya Ingress ke sath mil kar traffic ko exactly 10%, 20% par split karta hai.

3 Hands-on Steps

  1. Apni app ki purani kind: Deployment ko kind: Rollout mein convert karein.
  2. Blue-Green Test: Naya version deploy karein. Pehle wo ek "preview" URL par khulega. Verify karne ke baad promote karein toh live traffic foran naye par chala jayega.
  3. Canary Test: Steps define karein: 10% traffic → pause → 30% traffic → pause → 100%.
  4. Ek AnalysisTemplate lagayen, naye version ko jan boojh kar error throw karne wala banayen, aur dekhein Argo auto-rollback karta hai ya nahi.

4 Errors to Break + Fix

  • Stuck Rollout: Agar analysis fail ho jaye ya aap pause ko unpause (promote) karna bhool jayen, toh rollout hamesha "Paused" state mein phansa rehta hai.
  • Traffic not splitting: Agar aapne Rollout ke andar Gateway / HTTPRoute ka naam ghalat likh diya, toh traffic 100% v1 par hi rahega.

5 Best Practices (Pro Tips)

  • Hamesha Analysis + Auto-Rollback define karein. Raat ko 3 baje release ho aur phat jaye toh Argo khud sambhal le.
  • Canary ke steps ke darmiyan "Bake time" (intezar ka waqt) short rakhein (e.g. 2-5 mins) taake deployment boht lamba na ho.
  • Rollouts ko HPA (Horizontal Pod Autoscaler) aur PDB (Pod Disruption Budget) ke sath laazmi link karein.

Done-Check

  • Canary aur Blue-Green dono strategies test ho gayin, aur ek fail hone wala canary khud-ba-khud (auto) rollback ho gaya!
