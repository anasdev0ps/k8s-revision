1 Analogy (Samajhne ke liye)

Default K8s: Ek "Open-plan office" jahan har koi kisi se bhi ja kar baat kar sakta hai (All pods can talk to all pods).

NetworkPolicy: "Doors aur Keycards" lagana. Ab DB ke kamre mein sirf Frontend ja sakta hai, koi aur nahi!

2 Core Concepts

  • Default Allow-All: K8s mein by default koi firewall nahi hoti.
  • Default-Deny: Jaise hi aap kisi namespace par NetworkPolicy lagate hain, by default sab kuch **Deny** ho jata hai. Uske baad jo traffic allow karna ho usay explicitly allow karna parta hai.
  • Ingress / Egress: Ingress matlab "Aane wala traffic", aur Egress matlab "Jane wala traffic".
  • CNI Requirement: Network Policies kaam hi tab karti hain jab aapka CNI (jaise Calico ya Cilium) inhe support karta ho (Flannel support nahi karta).
  • CoreDNS: K8s ke andar ka DNS server jo service names (e.g. db-svc.default.svc.cluster.local) ko IPs mein badalta hai.

3 Hands-on Steps

  1. Agar Flannel chal raha hai toh usay hita kar Calico install karein (ya koi Policy-capable CNI).
  2. Ek Default-Deny policy lagayen taake sab traffic block ho jaye.
  3. Ek specific policy lagayen jo sirf Frontend pods se DB pods tak traffic allow kare.
  4. Ek random pod bana kar check karein ke us se DB ping/curl nahi ho rahi.
  5. CoreDNS ko restart kar ke ya port block kar ke dekhein ke DNS resolve hona band ho jata hai.

4 Errors to Break + Fix

  • Policy too strict: Aksar Default-Deny lagane se app DB se connect nahi kar pati aur timeout error de deti hai. Isay sahi label based rules add kar ke fix karein.
  • DNS failures: Agar Egress ko bhi deny kar diya, toh Pods CoreDNS (port 53) tak nahi pohnch payenge aur internet ya services resolve nahi hongi! (Hamesha port 53 UDP/TCP allow karein).

5 Best Practices (Pro Tips)

  • Hamesha Default-Deny strategy use karein, aur uske baad sirf zaroorat ka traffic allow karein (Zero Trust).
  • Policies humesha Labels ki buniyad par lagayen (IPs ki buniyad par nahi q k IPs change hotay rehte hain).
  • Production mein lagane se pehle Network Policies ko hamesha dev environment mein test karein.

Done-Check

  • Hacker pod se DB block ho gaya, lekin Frontend se DB chal raha hai. Aapne Firewall implement kar li!
