1 Analogy (Samajhne ke liye)

Helm: Kubernetes ka app installer hai (jaise Ubuntu mein apt ya Windows mein exe hota hai).

Chart: Yeh wo installable package hai jisme app ka sara code aur blueprints hain.

Values: Yeh wo "Config Knobs" (settings) hain jinse aap batate hain ke aapko app kahan aur kaise chahiye (e.g. database ka password kya hoga).

2 Core Concepts

  • Templating: Helm {{ .Values.replicaCount }} ki tarah placeholders use karta hai. Jab aap command chalate hain toh wo values.yaml se data utha kar final YAML banata hai.
  • Releases: Jab aap ek chart install karte hain toh usay ek "Release" kaha jata hai. (Jaise ek DB ki multiple releases ho sakti hain).
  • Install/Upgrade/Rollback: Helm ki super power! Aap easily version change (upgrade) kar sakte hain aur agar app crash ho jaye toh foran peeche (rollback) ja sakte hain.
  • Repos & Dependencies: Aap doosron ke charts (e.g. Bitnami) directly download kar sakte hain ya apne chart ke andar doosre charts ko as dependency rakh sakte hain (e.g. App ko DB chahiye).

3 Hands-on Steps

  1. Ek public chart (e.g. NGINX ya Redis) ko custom values ke sath install karein (helm install).
  2. Koi setting change kar ke helm upgrade chalayen.
  3. Kuch jan boojh kar galat karein aur phir jadu dekhein: helm rollback!
  4. Write your own chart: helm create my-app karein aur apni kisi app ka chart banayen.
  5. helm lint aur helm template --dry-run chala kar errors check karein bina apply kiye.

4 Errors to Break + Fix

  • Template render errors: Agar aapne bracket {{ }} ghalat band kiya ya variable ka naam values.yaml mein nahi hai toh render fail ho jayega.
  • Failed upgrade: Agar upgrade ke waqt pod crash ho jaye, toh cluster phans jata hai. Isay helm rollback se theek karein.
  • Values not overriding: Agar aapne command line par --set use kiya aur wo apply na ho raha ho (hierarchy check karein).

5 Best Practices (Pro Tips)

  • Har environment (Dev, Staging, Prod) ke liye alag values-dev.yaml, values-prod.yaml rakhein.
  • Hamesha --atomic flag use karein upgrade karte waqt, taake agar app fail ho toh Helm khud rollback kar de!
  • Apne banaye hue charts ki version ko git tags ke sath zaroor update karein.
  • Internet se uthaye gaye untrusted charts ko bina verify kiye blindly helm install mat karein.

Done-Check
