1 Analogy (Samajhne ke liye)

Interview Prep: Yeh aapki final cheat-sheet hai. Jab aap interview table par baithte hain, toh interviewer aapse maslay (Cases) poochta hai. Agar aapka dimagh har masle ka fauri Action bata de, toh naukri pakki!

2 The Master Cheat Sheet (Case ➜ Action)

Ye table hamesha yaad rakhein, ye real-world production issues ka nichor hai:

Real-World Case (Masla) Action (Hal)
Pod phansa hua hai (Pending) Check describe events ➜ verify resources/taints/PVC.
App ko traffic nahi mil raha Check Readiness probe ➜ verify Service Endpoints.
Zero-downtime release karni hai Blue-green (instant) or Canary (gradual) via Argo Rollouts.
ConfigMap change kiya par pod purana hai kubectl rollout restart ➜ ya checksum annotation use karein.
Production changes auditable honi chahiye Strict GitOps (ArgoCD) ➜ Koi manual `kubectl` allow na ho.
Same artifact sab environments mein chalana hai Promote Freight via Kargo ➜ (Dobara image build mat karein).
External IP <pending> hai (Bare-metal par) MetalLB IP pool aur L2 advertisement check karein.
ingress-nginx purana ho gaya hai Modern Gateway API (Gateway + HTTPRoute) par migrate karein.

3 Quick Reference (Triage Order)

Kisi bhi tootay hue pod ke liye hamesha ye commands is tarteeb se chalayen:

  1. kubectl get pods -A (Check status)
  2. kubectl describe pod <pod> -n <ns> (Check events & config)
  3. kubectl logs <pod> -n <ns> [--previous] (Check application errors)
  4. kubectl get events -n <ns> --sort-by=.lastTimestamp (Check cluster level issues)
  5. kubectl get pod <pod> -o yaml (Check exact running config)
